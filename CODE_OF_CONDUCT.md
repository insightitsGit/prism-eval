# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in Prism-Eval a harassment-free experience for everyone.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Using welcoming and inclusive language  
- Being respectful of differing viewpoints  
- Accepting constructive criticism  
- Focusing on what is best for the community  

Examples of unacceptable behavior:

- Harassment, trolling, or insulting comments  
- Publishing others’ private information  
- Conduct that would be inappropriate in a professional setting  

## Enforcement

Report issues to **security@insightits.com** or repository maintainers.

Maintainers may remove, edit, or reject contributions that violate this Code of Conduct.
