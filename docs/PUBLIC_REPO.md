# Community & public repository policy

This is a **public** open-source repository. Contributions are welcome under the [Apache-2.0](LICENSE) license and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## How to interact

| Need | Where |
|------|--------|
| Bug | [Bug report](https://github.com/insightitsGit/prism-eval/issues/new?template=bug_report.yml) |
| Feature | [Feature request](https://github.com/insightitsGit/prism-eval/issues/new?template=feature_request.yml) |
| Usage question | [Question](https://github.com/insightitsGit/prism-eval/issues/new?template=question.yml) |
| Security vulnerability | [Private advisory](https://github.com/insightitsGit/prism-eval/security/advisories/new) or security@insightits.com — **never** a public issue |
| Enterprise / SLA | [SUPPORT.md](SUPPORT.md) · [insightits.com](https://www.insightits.com) |

## Protections (already enabled)

- Secret scanning + push protection  
- Dependabot alerts + automated security updates  
- Private vulnerability reporting  
- `main` branch protection (PR + code-owner review + CI on 3.10/3.11/3.12; no force-push / no branch deletion)  
- Wiki disabled (reduces spam surface)  
- Workflows default to read permissions; fork PRs need approval to run workflows  

See [SECURITY.md](SECURITY.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
